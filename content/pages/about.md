DropGit is a free web app that lets you download an entire repository, a single folder, or a handful of files from GitHub and GitLab as a clean ZIP archive, with no Git installation, no account and no command line.

## Why we built it

GitHub's **Download ZIP** button only works on whole repositories. Developers, students and designers often want just one directory, such as a component, a template or a lesson, and ended up downloading hundreds of megabytes or learning Git commands they did not need. DropGit closes that gap: paste a link, pick what you want, and download.

## What you can do with it

- Download any public folder or repository as a ZIP with its original structure intact.
- Select individual files from an interactive file explorer and preview code and images in the browser.
- Check whether a GitHub username is available and explore developer profiles.
- Install it as a Progressive Web App on desktop or mobile.

## How it works

DropGit reads public repository information through the official GitHub and GitLab APIs, fetches the files you select, and builds the ZIP for you. Download history and your theme preference stay in your browser's local storage. Read more in our [Privacy Policy](/privacy).
