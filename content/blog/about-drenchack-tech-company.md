DropGit is a product of **Drenchack Tech Company** (DTC), a technology company based in Ghana. This article explains who we are, what we build, and the principles that guide our work.

You can visit the company site at [drenchack.vercel.app](https://drenchack.vercel.app/).

## What we do

Drenchack Tech Company works on "secure, modern and scalable digital solutions." Our services include:

- **Web development.** Fast, responsive websites and web applications built with modern tools such as React and TypeScript.
- **Cybersecurity.** Security reviews and hardening, plus hands-on learning material for people who want to understand how attacks and defenses work.
- **UI/UX design.** Interfaces that are clear, accessible and pleasant to use on both phones and desktops.
- **Bot development.** Automation that handles repetitive tasks and conversations.
- **IT services.** General technical support and advice for small businesses and organizations.

## Products we build

Alongside client work, we build our own products, usually to solve a problem we have run into ourselves.

- **[DropGit](/).** A free browser tool that downloads GitHub and GitLab folders, files and repositories as ZIP archives, with no Git installation needed. Read how it works in [How to download a single folder from GitHub](/blog/how-to-download-a-single-folder-from-github).
- **[Ludoka](/blog/ludoka-play-ludo-in-your-browser).** A browser-based Ludo game with computer opponents, pass-and-play and Classic and Africa rule sets.
- **[Gitty](/blog/gitty-chrome-extension-readme-generator).** A Chrome extension that helps developers generate animated READMEs and code explanations.

## How we work

A few principles show up across everything we ship:

1. **Security by default.** For example, DropGit validates every link on the server and blocks requests to private network addresses, so the tool cannot be used to probe internal systems.
2. **Respect for privacy.** Our tools avoid needing accounts where they do not have to, and keep preferences such as history and theme in your own browser. See the [Privacy Policy](/privacy) for details.
3. **Performance and accessibility.** Pages should load quickly, work on low-end phones and be usable with a keyboard and screen reader.
4. **Open source where possible.** DropGit is open source under the Apache License 2.0, so anyone can read the code.
5. **Ship, learn, improve.** We release small, useful versions and improve them based on feedback.

## Building from Ghana

Building software from Ghana means designing for real-world conditions: mobile-first usage, variable network quality and users who value apps that work offline. Those constraints push us toward lightweight, installable web apps instead of heavy downloads, which is why DropGit and Ludoka are both installable Progressive Web Apps.
